胜利油田岩心库（勘探开发研究院地质资料中心）paleogene

这一处在山东省东营市东营区。这里不是景区，没有旅游景区等级，也不是文物保护单位，它的正式身份是自然资源部地质资料的委托保管单位，是国内石油石化系统中集管理、处理、信息化与科研于一体的单体规模最大、功能最全、自动化程度最高的实物地质资料馆藏机构。库内设岩心立库区、观察厅、处理厅、超低温冷冻实验室、数字化室与岩心岩相展览馆，十四条巷道、一万六千多个货位，存放着自二十世纪五十年代末以来陆续取出的约十八万米地质岩心，理论库容约四十万米，另建有五个专业实验室。作为科普场所，它长期承担研学与公众开放任务，接待过中学师生、高校博士团与外国友人等团体；个人散客必须提前联系并获得批准，未预约不能进入院区。要去的话，岩心库在东营市东营区的西城一带，属辛店街道，与中国石化胜利油田分公司勘探开发研究院所在的聊城路相距不远，周边是成片的油田机关、科研院所与住宅区。这里不设售票窗口，也不接待临时上门的个人，参观主要通过胜利油田组织的公众开放日活动，或者由学校、科研院所、企业以团体名义提前联系安排，已经接待过中学生、高校师生与外国来访者等各类团体。想去的话，最好提前一两周通过油田的官方渠道或所在单位发函联系，说明人数、身份、时间与想看的内容，获准后按约定时间到门口，由工作人员统一带领进入。室内参观，不受天气影响，每次宜留出一两个小时；院区是门禁管理区，进院要登记并带身份证件，着装不要过于随意，长裤和平底鞋比较合适。

济阳坳陷的古近系几乎全部埋在地下，地面上是一望无际的黄河冲积平原与盐碱滩，找不出一处连续的露头；要看沙河街组与东营组，唯一可靠的实物就是钻井取出来的岩心。胜利油田岩心库就是这些井下实物的家，它藏了自二十世纪五十年代末第一口探井以来陆续取出的约十八万米岩心，是国内石油石化系统中单体规模最大、自动化程度最高的实物地质资料馆藏机构，同时是自然资源部地质资料的委托保管单位。库里分区明确，有岩心立库区、观察厅、处理厅、超低温冷冻实验室、数字化室和岩心岩相展览馆，堆垛机与搬运机器人能在几分钟内把高处的岩心送到眼前。岩相展览馆里陈列着一批标准岩相剖面与各类岩石、矿物、古生物与化石标本，从井下取出的第三纪化石也在其中。来这里看古近纪，看的不是山，而是一段段圆柱状的石头。

看什么 what you see先看见

进到立库区，最先感受到的是尺度：十几米高的钢制货架一条条排开，中间是巷道，堆垛机在巷道里来回穿行，存取岩心时几乎没有声音。岩心被装在长条的岩心箱里，一箱挨一箱码在货架上，箱侧贴着标签，写着井号、井深区间、层位与取心序号。把箱子搬到观察厅的工作台上打开，里面是切得整整齐齐的圆柱状岩心，粗细和成年人的拳头差不多，一段接一段按顺序排着，断面朝上，像一截截被切开的树干。有的岩心被沿轴面劈成两半，一半留作档案，一半用于观察与取样，劈开的那一面最平整，纹层、层面与生物碎屑看得最清楚；圆柱的外表面则常常留着钻井液蹭出的浅色边圈和取心筒划出的细痕。

颜色是井下岩心最直观的语言。沙河街组沙四上亚段的岩心多是灰褐与深灰的钙质纹层泥页岩，密密的明暗纹层一层压一层，薄的地方像书页，夹着浅灰白的白云岩与泥质白云岩条带，断面摸上去细腻发滑，指甲划过留下一道浅痕；沙三下亚段以油页岩、钙质泥岩和灰色泥岩为主，油页岩呈棕褐到灰褐，密度明显比旁边的泥岩轻，用指甲一划就卷起油亮的薄屑，掰开时有淡淡的油味，断面微微呈贝壳状。往上到东营组，颜色一下子亮起来，紫红、棕红与灰绿色的泥岩和砂岩互层，砂岩灰白，颗粒感明显，手指搓一搓能掉下细砂。含膏含盐的层段表面常常起一层白霜，手指一抹是咸的，那是地下水蒸发后留下的盐类。

化石要靠放大镜看。介形类最常见，只有芝麻粒大小，浅黄或灰白，两瓣对称的小椭圆壳，常常沿着层面整排整排地排列，密集的地方一平方厘米里能挤下好几个；腹足类的小螺比小米粒略大，螺环清晰，壳面有细生长线；双壳类的碎片呈弧形，带着同心纹。轮藻的藏卵器是更小的球形颗粒，表面有螺旋细胞留下的纹路，需要放大更多倍才看得清；沟鞭藻与疑源类则小到肉眼完全无能为力，只能在展厅的显微照片与薄片图像里见到它们的囊孢和刺突。岩心是档案，多数只能看不能摸，需要触摸的观察要在工作人员安排下进行；看的时候留意箱上的深度标签，把深度、颜色、岩性与化石连起来读，一段地层的故事就出来了。

周边情况 the surroundings它落在什么地方

岩心库所在的西城是胜利油田的大本营，街道笔直宽阔，楼房不高，路边绿化带后面常常就能看见慢悠悠起落的抽油机，空气里偶尔飘着一点油味。东营是一座因油而建的城市，东西两城分工明确，生活节奏慢，餐馆以鲁菜和本地河鲜海货为主，住一晚很方便。到东营可以坐火车到东营站再打车，也可以从济南、青岛方向走高速公路直达，市内公交与出租车都很便宜。城市很年轻，广场宽阔，人也少，走在外面不会觉得拥挤。

参观安排要提前做。岩心库没有售票窗口，也不接待临时上门的个人，主要渠道是油田组织的公众开放日，以及学校、科研院所、企业以团体名义的联系安排，中学生、高校博士团与外国来访者都曾成批走进这里。申请时说明人数、身份、时间与想看的内容，获准后按约定时间到门口，由工作人员统一带领进入；进院要登记并出示身份证件，参观过程中不要脱离队伍，也不要在立库区里奔跑。室内参观不受天气影响，但每次最好留出一两个小时，看得太赶，岩心背后的故事就全错过了。

西城以南的胜利石油科技馆是另一处石油主题的展馆，展陈里也有油田的岩心标本和第三纪古生物化石，但它近几年经历过搬迁与调整，开放时间时有变化，去之前务必先电话确认，免得白跑一趟。城里还有华八井的旧址，东营组的层型剖面就定在这口井的钻孔上，站在井边想想一个地层单位的名字竟来自脚下这口井，很有意思。再远一些是黄河口生态旅游区，可以看黄河入海的黄蓝交汇与湿地候鸟，十月到十一月芦花飞雪、鸟群南迁的时候最好；孤东海堤与天鹅湖也适合半日往返。若时间宽裕，把岩心库与黄河口串成一条线，正好把山东古近纪的地下与地表各看一半。

背后的原理 why it is so

济阳坳陷位于渤海湾盆地东南部，是在华北地台基底上发育起来的中新生代断陷与坳陷叠合盆地，古近纪是它最主要的裂陷期。以东营凹陷为例，北陡南缓，呈不对称的箕状，内部又被同沉积断层分成博兴、利津、牛庄、民丰等生油洼陷，以及北部陡坡带、中央背斜带、南部缓坡带等次级单元。古近系自下而上是孔店组、沙河街组和东营组，沙河街组再分为四段。沙四上亚段沉积时湖盆封闭、气候偏干，水体咸化，形成灰褐色的钙质纹层泥页岩与油页岩互层；沙三下亚段是半咸到微咸的深湖，浮游的沟鞭藻、疑源类与介形类繁盛，有机质顺层富集，构成了济阳坳陷最重要的烃源岩；沙三中亚段转为微咸到淡水的三角洲，砂泥互层；沙一段再度咸化，出现白云岩与泥质白云岩；到东营组沉积时，盆地由断陷向坳陷转换，湖盆先扩张后迅速收缩，沉积了紫红、灰绿与灰色的泥岩和砂岩。这些地层之所以只能在井下研究，是因为它们埋在几千米厚的新近系与第四系之下，地表一点不露，唯一连续的第一手记录就是岩心与岩屑。之所以特别倚重微体化石，是因为介形类、腹足类、轮藻、沟鞭藻、疑源类与孢粉这六个门类的个体都很小，在岩心里数量极大、分布连续，可以在米甚至更小的尺度上采样，而且它们对盐度、水深、温度与气候的变化极其敏感，一个门类换一种组合，往往就标志着一次湖平面的升降或一次气候转折。把它们叠合起来，就能建立起高分辨率的生物地层格架，既能定年代、对比井间层位，又能恢复古湖的盐度与深浅；相比之下，大化石在钻井过程中多半被破碎，反而不如这些小东西可靠。

现场怎么确认 how to verify

看岩心第一件事是读标签，别只看石头。标签一般给出井号、取心次数、顶深与底深、层位与编号，有的还标了方向箭头，上下不能颠倒；把相邻箱子的深度接起来，看看区间是否连续、有没有缺米数，缺的往往是因为收获率不足或岩心破碎。第二件事是分清新鲜面与陈旧面：刚剖开的面颜色最真实，久置的岩心会脱水开裂、氧化变浅，油页岩的褐色也会褪成灰黄，判断岩性要以新鲜断面为准。第三是别把岩石本身的结构当成化石，介形类的壳大小均匀、两瓣对称、表面光滑、常顺层面成排，而黄铁矿的细小颗粒呈立方体或不规则团块，有金属光泽、掂着更重；钙质结核则大小悬殊、断面致密。油页岩与碳质泥岩的分辨办法和露头上一样，指甲划出油亮卷屑、密度轻、带油味的才是油页岩。另外要分清岩心与岩屑：岩心是连续圆柱，深度准确；岩屑是钻井返上来的碎屑混合物，层位精度差。最后，岩心是不可再生的实物档案，不要擅自取样或反复触摸含油井段，取样须由管理方按规定办理。
