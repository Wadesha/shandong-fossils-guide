原理索引Principles

下面这些原理都是从具体的化石和露头里反推出来的。每一条先讲它说的是什么，再列出它在山东这套地层里落在哪些词条上。

化石带化石带是生物地层学里最基本的单位：在一个剖面上，某种或某组化石从出现到消失的那一段地层，就叫一个化石带。它的边界由生物事件定义，与岩性变化无关，因此可以在岩性完全不同的两套地层之间建立对应关系。

延限带延限带指的是某一分类单元从它在地层中首次出现到最终消失之间的全部层段。它由这一个单元自己的上下限决定，不掺杂其它化石。延限带的好处是不依赖人为约定，只要有连续剖面和足够标本就能建立；缺点是个别标本的采集偶然性会直接改变边界位置。

组合带组合带不看某一种化石的上下限，而是看一组化石共同出现的那一段地层。当单个属种延续时间短、分布又窄，难以单独支撑对比时，用组合反而更稳。山东前寒武系是组合带最典型的用武之地：那个时代没有硬壳化石，能用的只有叠层石形态组合和微古植物组合，于是鲁西土门群、鲁东蓬莱群、粉子山群、五莲群各自按「组合」来定时代。

标准化石标准化石指的是分布广、演化快、特征明显、易于识别的化石，只有同时满足这几点，它才能在大范围内用来判断地层的新老。分布广保证跨盆地可用，演化快保证时间分辨率高，特征明显保证不被误认。

指相化石指相化石不回答「这是什么时候」，只回答「当时是什么环境」。它靠的是生物对环境的耐受范围：珊瑚需要温暖清澈的浅海，龟鳖类要求长期有水，云杉一类针叶树偏好冷湿，底栖和沿岸型硅藻指示浅水。

埋藏学埋藏学研究的是生物遗体从死亡到被发现之间发生了什么。同一层位里保存下来的，往往不是当年生活的全部面貌，而是搬运、分选、破坏之后留下的那一部分。骨头滚圆说明经过搬运，贝壳完整说明原地埋藏，叶片只剩叶脉说明腐烂程度浅。

特异埋藏（Lagerstätte）特异埋藏是埋藏学里最极端的一种情形：软体、羽毛、皮肤、叶脉这些通常不可能保存的部分被完整保留下来，形成所谓化石宝库。条件是沉积速率高、颗粒细、底层缺氧、扰动少，生物一死就被细泥迅速封存。

叠层石叠层石是微生物席（以蓝细菌为主）一层层粘结、捕获沉积物后形成的层状构造，不是生物遗体，而是生物活动留下的构造。形态从柱状、锥状到层状都有，分辨它靠的是基本层的形态、柱体的分叉方式与侧壁特征。

䗴类计时器䗴类是有孔虫里已经灭绝的一支，个体像纺锤或米粒，内部由初房、隔壁与旋壁分隔，形态复杂且演化迅速。由于它生活在浅海、分布广、延续时间短，成为石炭—二叠纪最可靠的计时工具。

孢粉分析孢粉分析从细粒堆积中取样，用化学方法把花粉与孢子分离出来，在显微镜下分类统计各类植物的百分比。孢粉壁由孢粉素构成，抗腐蚀、产量极大，因此在看不到大化石的层位里也能取得植被信息。

海侵层与微体化石海侵层是海水短暂侵入陆地留下的沉积夹层，在平原区常以一层含海相微体化石的细粒沉积出现。识别它往往靠有孔虫与介形虫这类微体化石，因为它们的壳小、数量大，能在薄层里被找到。

生物与同位素互校生物地层给出的是先后顺序，同位素测年给出的是绝对年龄，两者性质不同，但可以互相校验。生物地层不依赖仪器，只要有连续剖面就能建立相对次序，代价是无法给出数字；同位素测年能给出数字，但需要合适的测年材料，且结果带有误差范围。
